# Sim-Life 🏡

Уютный мобильный 3D-симулятор жизни Влада и Алины. Личный проект для двух игроков.

## Статус: прототип 0.1.0

Есть: одна процедурная 3D-комната, мебель, два временных персонажа, мобильная камера, контекстное меню и базовые действия, несколько потребностей, прототипы карьер и локальное сохранение.

**Пока отсутствует:** настоящий мультиплеер, серверные сохранения, финальные модели персонажей, полноценные профессии, экономика и городские локации. Переключение между Владом и Алиной в этой сборке сделано исключительно для локального тестирования.

## Запуск

1. Установить Node.js (рекомендуется LTS).
2. В папке проекта выполнить `npm install` (если зависимости ещё не установлены).
3. Запустить `npm run dev`.
4. Открыть локальный адрес из консоли на компьютере.

Проверка: `npm run check` и `npm run build`.

## Важные решения

- Вертикальная ориентация телефона, без джойстика.
- Персонаж идёт к объекту по контекстной команде.
- Главные карьеры: реконструкция волос Алины, разработка/вайбкодинг Влада.
- Общий мир на двух устройствах — обязательная архитектурная цель, **ещё не реализованная**.
- Игровые товары будут использовать повторяемые оптимизированные 3D-основы.
- Личная информация и секреты не должны попадать в публичный репозиторий.
