# Sim-Life 🏡

**Уютный мобильный 3D-симулятор жизни Влада и Алины** — личная игра для двух человек. Цель: один общий дом, отношения, повседневная жизнь и две глубокие карьеры — разработка игр/ПО и реконструкция волос.

## Текущий этап: 0.2.0 + играбельные системы будущей 0.3

Это по-прежнему технический прототип, а не финальный визуальный стиль.

### Уже можно попробовать
- Два игрока в одном доме, разные входы, общий бюджет, навыки и прогресс.
- Контекстное управление: тап по предмету → подход по маршруту вокруг мебели → действие.
- Объятия и «дай пять» между Владом и Алиной: выполняются сразу, когда оба в сети, без обязательных подтверждений; новое действие прерывает текущую анимацию.
- **Первый целостный бытовой цикл:** кнопка магазина → 8 продуктов с серверными ценами → кухня с 6 рецептами → готовые порции в общем запасе → поесть за столом.
- При готовке сервер проверяет рецепты, расходует ингредиенты и создаёт две порции; при еде расходуется одна порция, восстанавливаются голод и настроение.
- Анимации подхода, помешивания на кухне и еды; лёгкая 3D-геометрия плиты с посудой. Это не финальные модели.
- Старые серверные сохранения версии 0.2 загружаются без потери денег и навыков; недостающие поля новой еды дополняются нулями.

**Пока нет:** отдельных 3D-магазинов и курьеров, серверной продолжительности работы, финальных персонажей, питомцев, настоящих карьерных систем, теста на двух физических телефонах и защищённого интернет-хостинга.

Проверено: сборка TypeScript/Vite, 12 целевых тестов экономики/сохранений/действий и Chrome smoke-тест на мобильном размере 390×844. Браузерный тест подтвердил реальную покупку за 30 ₽ через WebSocket и отсутствие исключений JavaScript.

## Запуск на Windows

Node.js v24+ и Git уже установлены на ALINA-PC. Файлы находятся в `D:\Sim-Life`.

1. Для первого запуска или после обновления кода: `npm install` и `npm run build`.
2. Двойной щелчок по `START_SIM_LIFE.cmd` или команда `npm run start`.
3. На этом же компьютере открыть `http://127.0.0.1:3101/`.
4. Сервер создаст закрытый локальный файл `D:\Sim-Life\server-data\access.json`. Двойной щелчок по `SHOW_INVITES.cmd` откроет его в Блокноте. Там разные ключи для Влада (`vlad`) и Алины (`alina`). **Не присылайте ключи в чат и не загружайте их на GitHub.**
5. На двух телефонах в **одной доверенной Wi-Fi сети** открыть `http://IP-КОМПЬЮТЕРА:3101/`. Выбрать своего героя, ввести соответствующий код. Если Windows спросит доступ Node.js к частным сетям, разрешить только **Private networks**.

Найти IP ПК: в PowerShell выполнить `ipconfig` и посмотреть IPv4 Address активного Wi-Fi/Ethernet адаптера.

**Не пробрасывать порт 3101 на маршрутизаторе:** текущий прототип использует HTTP/WS без TLS, предназначен только для доверенной домашней сети. Для удалённой игры из разных сетей понадобятся HTTPS, безопасный хостинг и отдельная проверка безопасности.

## Для разработчика

- `npm run dev` — сервер и Vite одновременно (`http://127.0.0.1:5173/`), WebSocket перенаправляется на порт 3101.
- `npm run check` — строгая проверка TypeScript.
- `npm test` — автоматические тесты правил, синхронизации и восстановления сохранений.
- `npm run build` — проверка и сборка клиента.
- `npm run start` — сервер с готовой сборкой и общим миром.

Серверные файлы `server-data/` исключены из Git, как и `node_modules/`, `dist/`, `.env`. Данные, секреты, фотографии и персональные материалы никогда не коммитим в публичный репозиторий.

## Организация

- `src/shared/protocol.ts` — общий протокол, типы, игровые действия.
- `server/logic.ts` — игровые правила и транзакции.
- `server/server.ts` — HTTP/WebSocket сервер и синхронизация двух игроков.
- `server/storage.ts` — персональные коды и атомарные сохранения.
- `src/core/network.ts` — клиент WebSocket, повторное подключение.
- `src/game/` — 3D сцена и персонажи.
- `docs/ARCHITECTURE.md` и `docs/ROADMAP.md` — архитектура и следующие этапы.
- `HANDOFF_LATEST.md` — актуальная передача проекта для нового чата.
