**Уютный мобильный 3D-симулятор жизни Влада и Алины** — личная игра для двух человек. Цель: один общий дом, отношения, повседневная жизнь и две глубокие карьеры — разработка игр/ПО и реконструкция волос.

## Архивный этап: 0.2.0 + играбельные системы будущей 0.3

Это по-прежнему технический прототип, а не финальный визуальный стиль.

### Уже можно попробовать
- Два игрока в одном доме, разные входы, общий бюджет, навыки и прогресс.
- Контекстное управление: тап по предмету → подход по маршруту вокруг мебели → действие.
- Объятия и «дай пять» между Владом и Алиной: выполняются сразу, когда оба в сети, без обязательных подтверждений; новое действие прерывает текущую анимацию.
- **Первый целостный бытовой цикл:** кнопка магазина → 8 продуктов с серверными ценами → кухня с 6 рецептами → готовые порции в общем запасе → поесть за столом.
- При готовке сервер проверяет рецепты, расходует ингредиенты и создаёт две порции; при еде расходуется одна порция, восстанавливаются голод и настроение.
- Анимации подхода, помешивания на кухне и еды; лёгкая 3D-геометрия плиты с посудой.
- **Визуальный этап №4:** персонажи действительно садятся на диван/стул, работают сидя за столом и ложатся вдоль кровати; при следующем действии поднимаются и идут дальше. Дом дополнен отделкой стен, деревянными досками пола, подоконным видом на сад, полками, текстилем, декором кухни и тёплым подвесным светом. Геометрия лёгкая и переиспользуемая. Это не финальные модели.
- **Этап №5 — Верделл и Симба:** два отдельных интерактивных 3D-питомца (чёрный пушистый шпиц и рыжий полосатый кот), мягкое движение/реакции, персональные лежанки и миски. По тапу на питомца или кнопке 🐾 доступны покупка корма, кормление, игра, поглаживание и расчёсывание. Сытость, радость, привязанность и запас корма хранятся на сервере и общие для двоих. Геймплейные потребности пока не убывают сами со временем; простые перемещения питомцев — локальная визуальная анимация.
- **Этап №6 — живые занятия:** серверный таймер выполнения работы, учёбы, сна, отдыха, готовки, еды и ухода за питомцами. Прогресс виден обоим игрокам, хозяин персонажа может нажать «Прервать». Награда, расходы на ингредиенты и изменения потребностей применяются лишь при успешном завершении. Кухня и рабочий стол эксклюзивны, одновременно можно заниматься разными делами. При отключении задача отменяется без награды.
- **Этап №7 — новое лицо Sim-Life:** Влад и Алина получили новые стилизованные мобильные 3D-модели — характерные многослойные причёски, выразительные лица с морганием, более цельные пропорции, разные комплекты одежды и обуви. Верделл получил объёмный чёрный пушистый силуэт шпица; Симба — рыжие полосы, кошачью мордочку, уши и хвост.
- **🔎 Посмотреть модели:** кнопка в интерфейсе приближает камеру к любому из четырёх героев. Можно повернуть камеру пальцем, приблизить её ещё сильнее и вернуться ко всему дому.
- Старые серверные сохранения версии 0.2 загружаются без потери денег и навыков; недостающие поля еды и питомцев безопасно дополняются при загрузке.

**Пока нет:** отдельных 3D-магазинов и курьеров, длительных многодневных задач и офлайн-прогресса, финальных моделей и анимаций персонажей/питомцев, системы роста/старения питомцев, глубоких карьеров, теста на двух физических телефонах и защищённого интернет-хостинга.

Этап №7 менял только клиентские 3D-модели и камеру. Проверены TypeScript/Vite build, 2 теста мебельных поз и Chrome-визуализация в мобильном размере 390×844, включая просмотр всех четырёх моделей и возвращение в комнату. Серверные тесты не повторялись, поскольку сервер и экономика не менялись. Производительность на физических iPhone и Android пока не измерена.

## Запуск на Windows

Node.js v24+ и Git уже установлены на ALINA-PC. Файлы находятся в `D:\Sim-Life`.

1. Для первого запуска или после обновления кода: `npm install` и `npm run build`.
2. Двойной щелчок по `START_SIM_LIFE.cmd` или команда `npm run start`.
3. На этом же компьютере открыть `http://127.0.0.1:3111/`.
4. Сервер создаст закрытый локальный файл `D:\Sim-Life\server-data\access.json`. Двойной щелчок по `SHOW_INVITES.cmd` откроет его в Блокноте. Там разные ключи для Влада (`vlad`) и Алины (`alina`). **Не присылайте ключи в чат и не загружайте их на GitHub.**
5. На двух телефонах в **одной доверенной Wi-Fi сети** открыть `http://IP-КОМПЬЮТЕРА:3111/`. Выбрать своего героя, ввести соответствующий код. Если Windows спросит доступ Node.js к частным сетям, разрешить только **Private networks**.

Найти IP ПК: в PowerShell выполнить `ipconfig` и посмотреть IPv4 Address активного Wi-Fi/Ethernet адаптера.

**Не пробрасывать порт 3111 на маршрутизаторе:** текущий прототип использует HTTP/WS без TLS, предназначен только для доверенной домашней сети. Для удалённой игры из разных сетей понадобятся HTTPS, безопасный хостинг и отдельная проверка безопасности.

## Для разработчика

- `npm run dev` — сервер и Vite одновременно (`http://127.0.0.1:5173/`), WebSocket перенаправляется на порт 3111.
- `npm run check` — строгая проверка TypeScript.
- `npm test` — автоматические тесты правил, синхронизации и восстановления сохранений.
- `npm run build` — проверка и сборка клиента.
- `npm run start` — сервер с готовой сборкой и общим миром.

Серверные файлы `server-data/` исключены из Git, как и `node_modules/`, `dist/`, `.env`. Данные, секреты, фотографии и персональные материалы никогда не коммитим в публичный репозиторий.

## Организация

- `src/shared/protocol.ts` — общий протокол, типы, игровые действия.
- `server/logic.ts` — игровые правила и транзакции.
- `server/server.ts` — HTTP/WebSocket сервер и синхронизация двух игроков.
- `server/storage.ts` — персональные коды и атомарные сохранения.
- `src/core/network.ts` — клиент WebSocket, повторное подключение.
- `src/game/` — 3D сцена и персонажи.
- `docs/ARCHITECTURE.md` и `docs/ROADMAP.md` — архитектура и следующие этапы.
- `HANDOFF_LATEST.md` — актуальная передача проекта для нового чата.

**GitHub:** https://github.com/Ssyap4/Sim-Life. Старый аккаунт `Syapbl4` не используется.


## Визуальный этап №8 — уютный дом
Стилизованная мебель и предметы интерьера собраны в `src/game/InteriorArt.ts`: мягкий диван с подушками, многослойная кровать, модульная кухня, рабочее место разработчика, телевизор, журнальный столик и ковры. Общие геометрии и материалы рассчитаны на мобильный WebGL. Существующие меню, серверные действия, автоподход и синхронизация не менялись.
Проверка: `npm run build`; `npx tsx --test server/tests/interior.test.ts server/tests/poses.test.ts server/tests/navigation.test.ts`. Для мобильного Chrome — `npx tsx .ui-test/stage7Smoke.ts` (локальный тестовый сервер и временные одноразовые коды, скриншоты в исключённой из Git папке).
