# Sim-Life 0.4 · Живой район

Ветка `feat/living-world-locations` основана на `feat/household-economy-plus` (`9e3121a`). Дом, GLB-модели, потребности, режим суток, семейные финансы и шесть подработок остаются доступны. Новая семья начинает с 2 500 ₽.

## Запуск

Работайте из отдельной папки проекта. Для облачной проверки использован `/workspace/Sim-Life-World`, для Windows подойдёт отдельный каталог `D:\Sim-Life-World`. Папка тестовой экономики+ может оставаться открытой и работающей независимо.

```bash
npm ci
npm run build
HOST=127.0.0.1 PORT=3111 SIM_LIFE_DATA_DIR=server-data npm run start
```

На Windows в этой папке можно запустить `START_SIM_LIFE.cmd`. В режиме разработки `npm run dev` открывает Vite на 5175 и проксирует WebSocket на 3111. Если задаёте свой `PORT`, используйте его и для Vite, и для сервера. `SIM_LIFE_DATA_DIR` указывает на отдельную папку данных. При запуске из новой папки сервер создаёт приватный `server-data/access.json`; коды не отправляйте в чат и не добавляйте в Git. Для тестирования с двух телефонов используйте доверенную локальную сеть. Сервер в приведённой команде привязан к loopback, поэтому такое подключение доступно только на машине запуска.

На первом входе можно отметить «Запомнить вход на этом устройстве». Браузер хранит случайный токен, а отдельный серверный файл содержит только его хеш, роль и срок действия (30 дней). Токен восстанавливает выбранного персонажа и его место после перезагрузки. «Выйти и забыть устройство» в меню карты удаляет локальное доверие и отзывает токен. Сменить персонажа можно после выхода.

## Пять мест

| Место | Игровой цикл |
| --- | --- |
| Дом | Открыть холодильник или шкаф, увидеть запасы, подобрать рецепт, приготовить еду, забрать доставку и разобрать пакеты |
| Квартал | Идти по щелчку по тротуару, отдохнуть на скамье, подойти к вывеске и пройти в соседнее место |
| Супермаркет | Подойти к нужному отделу, положить товары в корзину, пройти к кассе, проверить состав и оплатить |
| Кафе | Заказать у терминала, дождаться готовности, забрать на выдаче, сесть и поесть за общим или отдельным столиком |
| Парк | Пройти по дорожкам, отдохнуть, сделать зарядку или взять и выгулять Верделла |

Карта ведёт прямо в доступную локацию, а дверные переходы требуют подхода. Каждый персонаж сохраняет своё место. Оба пользуются общими часами, бюджетом, запасами и финансами. На смене персонаж скрыт и не может путешествовать. После смены он остаётся в сохранённом месте. Объятия и «дай пять» доступны только при встрече в одной локации. Симба остаётся дома. Верделла можно взять из дома по карте или с площадки в парке. При отъезде, начале смены или отключении сопровождающего Верделл возвращается домой.

## Домашние занятия

- Высокий холодильник стоит справа от кухонной столешницы. Нажмите на дверцу, чтобы персонаж подошёл, открыл её и показал фактические запасы. Ингредиенты можно выбрать прямо из холодильника или навесных полок. У плиты, мойки и чайника свои точки подхода и направления движений рук.
- Верделл и Симба ходят по рассчитанным на сервере маршрутам, пользуются собственными лежанками, мисками и туалетами. Сытость, энергия, туалет, радость и привязанность видны в меню питомца. Когда питомец заканчивает есть, сервер списывает одну порцию из его реального запаса. При пустом запасе питомец ждёт корм. Маршруты, положение и потребности сохраняются вместе с семьёй.
- Свободные персонажи дома иногда садятся перед телевизором, играют на компьютере, играют с питомцем или разговаривают друг с другом. Эти занятия идут по общим маршрутам и сами по себе не меняют шкалы. При значении потребности 8% или ниже сервер может запустить обычное действие ухода за собой. Автоматические действия прерываются при следующей игровой команде, а обычная смена, готовка, прогулка и ручные задачи имеют приоритет.
- Аватар отсутствующего игрока отдыхает в домашней сцене. Потребности этого игрока не восстанавливаются от фонового сна. При входе он возвращается к сохранённой локации и сразу получает управление.

## Экономика и сохранения

- У магазина тот же каталог и те же цены, что у семьи. Корзина видна у персонажа, её можно редактировать и очищать. При выходе из магазина неоплаченная корзина сбрасывается. Оплата атомарно проверяет остаток денег и вместимость уже имеющихся хранилищ, затем записывает расход и добавляет товары. Распаковка меняет только визуальное состояние и комфорт.
- Дистанционная доставка использует прежний каталог. Сбор 149 ₽ и стоимость товаров удерживаются при заказе. Через 18 игровых минут заказ появляется у двери. Продукты переходят в семейные запасы только при получении. Если места нет, оплаченный заказ сохраняется и остаётся доступным.
- Кафе оплачивается из общего бюджета. Выдача доступна через две игровые минуты, а эффект еды или напитка применяется при успешном завершении действия за столом. Заказ сохраняется даже при выходе из кафе.
- Для новых оплат используется отдельный счётчик операции на роль. Повторная отправка прежнего счётчика не списывает деньги и не добавляет товары. Старый протокол покупки остаётся доступным старым клиентам.
- Версия формата сохранения остаётся 2. Старому файлу добавляются пустые поля нового мира и местоположение «дом». Деньги, навыки, запасы, питомцы и активные смены сохраняются. Доставка и кафе используют обычные игровые часы, которые останавливаются при отсутствии обоих игроков.

## Отрисовка

Один рендерер, одна камера и один игровой цикл. Прежний дом хранится как фиксированный тёплый кеш. Вне дома создаётся только текущая внешняя сцена. При уходе уникальные геометрии, материалы вывесок и фонарей, текстуры и списки отрисовки освобождаются. Переиспользуемые геометрии и материалы, персонажи и их анимационные узлы сохраняются. Невидимые персонажи и питомцы не обновляют анимацию. Отдельные небольшие упаковки сгруппированы по материалу. Сохраняются мобильные лимиты DPR и теней, режим осмотра и диагностика `?perf=1`.

Модели продуктов условные, количество всегда читается в корзине и списках. Анимации подготовки, пользования полками и готовки используют общие движения. Очень длинный маршрут готовки может сразу вести к плите. В кафе нет бариста, на улице нет машин, в парке нет NPC и сложного ИИ.

## Воспроизводимая проверка

```bash
npm run build
npm test
curl -fsS http://127.0.0.1:3111/health
```

Проверять игровой сценарий лучше на отдельной тестовой семье, с двумя браузерами или устройствами. За Владом удобно открыть «Карту → Супермаркет», взять молоко в холодильной витрине и оплатить его у кассы. Пока Влад в магазине, Алина может приготовить омлет. После перезагрузки Влад должен остаться в магазине. Затем можно встретиться в кафе, взять заказ и выбрать один столик. Доставка забирается при нажатии на коврик у двери после сообщения о прибытии.

В Chromium с мобильной областью `390 × 844` проверены касания отделов и кассы, готовка второго персонажа в это же время, повторный вход в магазин, выдача напитка и совместное действие в кафе, прогулка с Верделлом и получение доставки. Домашняя проверка подтвердила открывание холодильника, направление персонажа у плиты, общий расход корма, сон при отключении и отмену автоматического действия командой игрока.
