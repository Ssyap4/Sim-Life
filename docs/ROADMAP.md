# Дорожная карта Sim-Life

Работаем крупными законченными обновлениями, но только после тестов. Автор утверждает окончательные игровые решения.

## 0.1 — первая 3D-комната ✅
Камера, временные Влад и Алина, мебель, первые контекстные действия.

## 0.2 — серверный фундамент ✅ (код), тест на телефонах впереди
Общий бюджет, продукты, навыки, WebSocket, раздельный доступ, серверные сохранения, первые учебные карьеры, тесты.

## 0.3 — качественный совместный быт
- Движение вокруг мебели: сетка навигации, сидение у реальной точки действия, стабильная анимация.
- Серверно управляемая продолжительность действий и их прерывание.
- Базовые потребности со временем и с учётом онлайн/офлайн.
- Меню взаимных действий между Владом и Алиной.
- Начальные питомцы: Верделл (чёрный шпиц) и Симба (рыжий кот).
- Тест производительности на iPhone и Android.

## 0.4 — первая полноценная бытовая вертикаль
- Продуктовый магазин как отдельная маленькая 3D-локация, полки-каталоги, реальные покупки ингредиентов.
- Кухня с несколькими рецептами, переиспользуемые анимации, общий инвентарь.
- Реалистичная доставка еды / предметов с курьером и подтверждением.
- Заменяемая мебель, расстановка без искусственных лимитов количества, синхронизация конфликтов.

## 0.5 — две главные карьерные вертикали
- **Алина:** курсы реконструкции/восстановления волос, диагностика, материалы, первые процедуры, клиенты, репутация, собственное рабочее место.
- **Влад:** биржа задач разработки, навыки, заказы, сроки и тестирование, первые проекты.
- Мини-игры с разумной возможностью автоматического завершения.

## Следующие крупные обновления
Здоровье, городские локации, NPC, кафе, транспорт, расширение бизнесов, управление студией реконструкции волос, игровая студия разработки с mini-Tycoon, PWA и защищённый хостинг для игры из разных сетей.

## Принципы качества
Красивый мягкий стилизованный 3D, небольшой расход памяти и нагрузки на телефоны. Большой ассортимент через карточки и общие лёгкие модели. Действия предметов связаны между собой. Не создаём The Sims целиком, делаем интересную уютную игру для двоих.
