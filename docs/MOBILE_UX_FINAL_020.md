# Sim-Life 0.20 — финальная доработка мобильного UX (Draft)

Основа: `feat/mobile-touch-native-020` (содержит визуальную 0.20 и предыдущую обработку жестов).
Рабочая ветка: `feat/mobile-ux-final-020`. Основной `main` / семейные сохранения **не менялись**.

## Что изменилось
- Мелкие 3D-предметы: при отсутствии точного попадания на мобильном экране используются 8 дополнительных лучей в радиусе 9–18 CSS-пикселей. Выбор отдаёт предпочтение объекту, ближайшему к точке пальца, слегка учитывая глубину. Геометрия предметов и коллизии не меняются; дополнительные лучи выполняются **только при нажатии**, а не на каждом кадре.
- Короткие круги отклика над точкой выбора/перемещения/размещения мебели. Элемент не ловит касания, сам удаляется после CSS-анимации; режим уменьшенного движения поддержан.
- Компактная кнопка `⌂` сбрасывает камеру к общему виду текущей локации. Она расположена в отдельном нижнем левом углу над игровым HUD, **не мешает** верхним часам/деньгам/карте/просмотру моделей.
- На каждом игровом клиенте запоминается позиция и точка наведения свободной камеры при перемещении между локациями; возврат восстанавливает знакомый ракурс (в течение одной игровой сессии). Осмотр персонажа и автоматический кинематографический перелёт не сохраняются как пользовательский вид.
- Контекстные меню: прозрачный для сцены верхний заголовок фиксируется при прокрутке, кнопка закрытия имеет касательную область не меньше 44 px, длинные действия прокручиваются без прокрутки страницы. Тап по свободной сцене закрывает меню **без отправки команды ходьбы**.
- Android аппаратная/браузерная «Назад» (и Safari browser back): сначала внутренний экран игрового телефона → главный экран телефона → закрытие телефона; затем другие открытые панели. История пополняется только временным защитным шагом, когда игровой интерфейс открыт, и возвращается после закрытия. Пауза не сбрасывается чужим нажатием «Назад».
- На Android/iOS фокусированный поиск использует `VisualViewport`: при открытой системной клавиатуре игровое окно приложения учитывает оставшуюся видимую высоту, поле прокручивается в область видимости. Текстовые поля остаются редактируемыми; реальный рендер Canvas не пересчитывается от изменений только виртуальной клавиатуры.
- Необязательный тёплый тактильный отклик на поддерживаемых устройствах. Настройка находится в телефоне → «Жизнь и привычки» → «Удобство управления» и сохраняется **локально**, по умолчанию отключена; iOS Safari без веб-вибрации получает только визуальный отклик.
- Для iPhone 11 нужны стандартные safe areas (чёлка и Home indicator), отдельной адаптации под Dynamic Island **нет**.

## Проведённые проверки
- `npm run build` (TypeScript и Vite) — успешно.
- Профильные тесты: жесты, очередь действий, мобильное кадрирование, кооперативная пауза, распознавание уменьшенного визуального окна при клавиатуре.
- Лично выполнено тестирование Chrome touch emulation **414×896 (iPhone 11 CSS размер)** и **320×568**, DPR 2. Проверены вход без кодов, игровая сцена, размещение кнопки камеры, телефон и настройки, вложенный экран, два нажатия Back подряд, закрытие контекстного меню кнопкой Back, тап на сцену за меню без команды ходьбы, доступность 44px крестика, отсутствие горизонтальной прокрутки, отсутствие ошибок браузера. Снимки — локально `D:\Sim-Life-020-VisualQA`, не в GitHub.
- Физические iPhone 11 / Android и настоящее появление экранной клавиатуры в Mobile Safari **не эмулируются полностью**. Перед утверждением `main` нужна ручная проверка на устройстве и наблюдение за FPS.
