# Sim-Life 0.33.0 — Гардероб и новый район

Владелец утвердил релиз 24.11.2026. Фактическую установку сверять по main, тегу и /health.
- Полноценный магазин одежды «Стиль», пешком/на машине, женский и мужской ассортимент, примерка, корзина, касса, купленные комплекты, два штатных шкафа дома. По 12 образов включая исходный, у Алины четыре комплекта с шортами, у Влада спортивный костюм и разнообразные повседневные комплекты. Индивидуальная обувь. Экспорт GLB/Blend в облаке, без тяжёлого локального рендера. Изолированная примерочная использует тот же рендерер, отдельную сцену и камеру, не меняет реальный наряд до покупки и переодевания дома. Не вводить стирку/грязь/штрафы.
- Android Chrome и Firefox: обычный режим AA включён, low-power, высокий фактический DPR; не возвращать мыльный emergency safe для обычного Chrome. Пользователь подтвердил исправление на физическом Android. iPhone не менять.
- Отдельная промзона, указатель на выезд из района, пеший/автомобильный путь и возвращение, два склада Ozon/WB с крышными вывесками, запуск смен у склада и через телефон. Склады ранее были только закадровыми работами; остальные здания сохранены.
- IT и маркетинг 4400/5400/6400/7400/9400 ₽, детейлинг 4300/5300/6300/7300/9300, клиника 3900/4900/5900/6900/8900 за полную смену. Такси 3700–6700, курьер 3200–6000, склады 5000–6800; зооняня 2300–3300 (6–7 ч), личный водитель 3200–4500 (7–8 ч). Бариста/инвентаризация сняты с биржи. Премии и досрочный уход сохранены.
- Сбросы по новому решению владельца: каждый тестовый апдейт — 100k и чистый прогресс, сохраняем размещённые предметы. При утверждённом основном выпуске — чистый старт со штатной мебелью, без купленных предметов, обычный начальный баланс; сохранить access.json и доверенные устройства. Скрипт server/reset-release.ts, только при релизе, не обычном рестарте.
- Проверены профильные тесты одежды, примерочной (геометрия кадра), Android, промзоны (27 тестов), зарплат (24 теста), сборки. Пользователь проверял магазин и гардероб вживую, одобрил итог. Не утверждать, что финальные кадры изолированной примерочной проверены лично: автоматическая геометрия не равна визуальному прогону.
- Следующий этап: электроника. Оставшиеся цены и семейную экономику проверять при обсуждении баланса; не менять произвольно согласованные ставки. Магазины мебели, зоотоваров и косметики позже. Ветеринарка — отдельная будущая система: болезни только при длительном серьёзном игнорировании еды и внимания, ресепшен, запись по телефону, NPC, диагностика, лечение; использовать существующую карьеру Алины. Две главные будущие профессии пока не начинать.
