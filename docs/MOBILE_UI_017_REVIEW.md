# Sim-Life 0.17 — mobile-first интерфейс и QA

## Обязательный стандарт
Sim-Life рассчитан прежде всего на **вертикальный экран смартфона**. ПК остаётся полноэкранным способом запустить ту же игру, но его широкая картинка **не является эталоном** дизайна или проверки UI. Постоянное правило внесено в `AGENTS.md`. Все будущие крупные правки интерфейса проверять лично по скриншотам и касаниям в мобильном масштабе, не только автотестами. Целевые ширины: 320, 360, 390, 430 px; безопасная зона, 44px touch-targets, читаемые русские строки, скролл и отсутствие непреднамеренного горизонтального переполнения.

## Исправления в ветке 0.17
- **Телефон:** при открытии магазина/подработок скрыта дублирующая шапка телефона (вложенное приложение имеет свою кнопку закрытия), увеличена высота полезной области на низких экранах, уплотнены плитки приложений. Сохранено переключение вкладок и доступность закрытия.
- **Доставка:** длинный заголовок сокращён; один полный столбец с читаемыми карточками продуктов на телефоне; кнопки «+ / −» не меньше 44×44; поиск и предложения не меньше 44 px по высоте; компактная корзина с реальной суммой товара/доставки. Ёмкость холодильника/полок остаётся во вкладке «Запасы», лишняя повторная полоска вверху каталога на мобильном скрыта.
- **Стабильность покупок:** частые серверные снапшоты о движении персонажей/потребностях больше не перестраивают магазин без изменения важных данных бюджета, запасов, платежей и состояния продуктов. Это помогает не терять точку нажатия при медленных мобильных устройствах.
- **Готовка:** реальный выбор рецептов на кухне/гриле перенесён вверх списка действий; есть поиск, переключатель «Все / Можно приготовить», число доступных блюд, краткое объяснение недоступности, раскрываемый состав и стоимость порции; отдельный высокий скроллируемый лист для выбора блюд на телефоне.
- **Мебель:** поиск всегда сверху, категория/стиль/цвет/количество раскрываются по желанию через компактную кнопку. На узких экранах карточки строго в один столбец с крупным превью и удобными кнопками; старый макет с двумя узкими карточками вызывал непригодные вертикальные столбики текста. Баланс и посылки отображаются компактно.
- **Потребности:** на ширине до 380 px обе колонки превращаются в последовательные читаемые блоки персонажей со скроллом.
- **Прочие поверхности:** скорректированы мобильные отступы и размеры диалогов, задана компактная стилистика для подработок, применён `prefers-reduced-motion`. Все изменения ограничены портретными мобильными условиями; стандартный полноэкранный ПК не переделывался.

## Ручной мобильный QA в изолированном предпросмотре
- **390×844, 320×568, 430×932**: лично просмотрены реальные 3D-дом и верхний HUD, потребности, главная телефона, магазин с поиском/запасами/финансами, подработки, «Жизнь и привычки», питомцы, мебель и мобильные действия. Браузерная эмуляция touch + Playwright/Chrome, не физический телефон.
- **320×568 после исправления**: товары видны сразу, без второго телефонного заголовка; кнопки корзины работают, итог для тестовой упаковки молока 95 ₽ + 149 ₽ доставки = 244 ₽. Физически подтверждён новый одноколоночный мебельный макет: ширина сетки/карточки 294px, ширина документа 320px, фильтры раскрываются.
- **390×844, реальный тап по 3D-плите**: открывается новый список готовки, показывает 14 из 15 доступных рецептов при тестовых запасах, поиск «суп» даёт домашний куриный суп, состав открывается отдельным нажатием. Нет клиентских ошибок JavaScript в этом сценарии.
- Запуск в изолированной папке данных `D:\Sim-Life-017-VisualReview\MobileAudit-017`, отдельный порт 3137 и только там вход без кода. Семейные сохранения 0.16/0.17 и основная игра не изменены, покупок не совершалось.
- **360×780:** дополнительно проверены 12 разделов игрового телефона — финансы, подписки, ЖКХ, интернет, связь, календарь, семья, питомцы, обучение, карьера, отношения и жизнь/привычки. Во всех этих разделах ширина содержимого равна ширине прокрутки, нет горизонтального обрезания, маленьких видимых кнопок и ошибок JavaScript. Скриншоты карьеры, обучения, календаря и потребностей просмотрены лично. На **настоящем смартфоне** FPS, фактическое поведение виртуальной клавиатуры и жесты навигации не измерялись — не объявлять их проверенными.

## Для следующих изменений
Проверять каждый путь из HUD через реальные тап-сценарии на мобильном: тап по плите → список блюд → поиск/фильтр/состав → приготовление; телефон → доставка → поиск с первой буквы → корзина → заказы; мебель → поиск/фильтры → превью → установка/перемещение; потребности/питомцы/карьера/обучение/карта; неудобства устранять до утверждения версии. Крупные изменения обязательно просматривать глазами **на мобильных скриншотах**, а не на широком мониторе.
