# Sim-Life 0.20 — управление касаниями на Android/iOS (Draft)

Основа: `feat/visual-world-pause-020` (черновик 0.20, PR #41).
Ответвление: `feat/mobile-touch-native-020`, **не основная версия**.

## Касания и управление камерой

- Одиночный тап по 3D-сцене выбирает объект/персонажа либо отправляет команду ходьбы.
- Смещение до 14 CSS-пикселей внутри одного касания **не** двигает камеру: обработчик сцены перехватывает `pointermove` до документного обработчика `OrbitControls`.
- При настоящем проведении пальцем камера сдвигается; такое движение **не** отправляет команду на взаимодействие.
- Два пальца: щипок приближает/отдаляет **игровую камеру**, сдвиг двух пальцев двигает её, скручивание вращает. Убрано конфликтующее двойное вращение `DOLLY_ROTATE`.
- После любого движения двумя пальцами их отпускание не вызывает ложный тап.
- Повторный тап в то же место сцены за 290 мс подавляется, но на соседнем предмете — нет. Быстрые нажатия по кнопкам магазина и клавиатуре **не ограничиваются**.
- Удержание более 550 мс не выбирает случайный предмет по отпусканию. `pointercancel` и потеря захвата очищают состояние.
- Мышь/перо на компьютере сохраняют обычную обработку.

## Ощущение мобильного приложения

- На игровом HUD и меню `touch-action: manipulation` запрещает браузерное увеличение **двойным тапом**; на Canvas — `touch-action: none`, поскольку масштаб управляется `OrbitControls`.
- Подавлено случайное выделение, появление «скопированного текста»/системного меню при долгом касании неинтерактивной игровой надписи.
- Исключения для настоящих `input`, `textarea`, `select`, `contenteditable` и `data-allow-selection`: выбор текста и клавиатура сохранены.
- Элементам ввода на сенсорных устройствах назначен размер текста не меньше 16 px, чтобы исключить автоувеличение страницы при фокусировке на iPhone.
- Сохранены вертикальные свайпы длинных меню, горизонтальная прокрутка фильтров и системные безопасные отступы.

## Проверки

- TypeScript + Vite: `npm run build` без новых ошибок.
- Десять отдельных тестов касаний, остальные — выборочные профильные тесты.
- **Практическая проверка:** Chrome headless с мобильным touch emulation на 390×844 и 320×568. Двойной тап по HUD: `visualViewport.scale === 1`, выделенный текст пустой. Сдвиг пальца на Canvas больше порога: ноль команд `walk`. Щипок: ноль случайных команд и ноль браузерного увеличения. В телефоне свайп сдвинул прокрутку с 0 до 160 px на экране 320×568. Проверено, что `selectstart` блокируется на HUD, но разрешён в полях ввода.
- Снимки QA на компьютере: `D:\Sim-Life-020-VisualQA`. Они **не** входят в GitHub и не содержат приватных кодов.
- Физический телефон и Mobile Safari/iOS ещё не проверялись: до выпуска убедиться в стабильности на настоящих Android/iOS.
- Игровой баланс, сетевые правила, структура кнопок и `server-data` не изменялись.

## Сохранность

Основной `main`, семейные сохранения, данные доступа и production-сервер 3111 не затрагиваются. Мобильный предпросмотр на порту 3134 использует отдельные тестовые данные.
