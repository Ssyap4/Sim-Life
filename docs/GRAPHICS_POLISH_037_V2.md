# Graphics Polish 0.37 v2 — мебель

Поверх 2b0cc81. Две общие карты 256×128 и 128×128: древесные волокна, сучки, тканое переплетение. Материалы клонируются после batching, не изменяют глобальные материалы героев. Покупная мебель, магазин, призрак размещения используют общий модельный путь. Существующие карты сохраняются. Штатные деревянные поверхности и ткань подушек, декоративная окантовка дивана, пуговицы изголовья, отделка ТВ-тумбы, края дорожки на столе. Геометрия персонажей, размеры и точки взаимодействия не изменены. 9/9 профильных тестов, TypeScript и Vite прошли; бюджет тестового интерьера 117 → 120 мешей, 32 shadow flags без изменений. Реальный FPS и визуальный осмотр новой версии не подтверждены. Main не трогать. Погода пока только визуальные пресеты, полноценная 0.39 позже.
