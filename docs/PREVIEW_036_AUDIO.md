# 0.36 v1 — Живой звук (preview)
- Клиентский Web Audio mixer, один контекст, 24 голоса максимум, настройки громкости локальны, звук после касания, пауза/выход/скрытая вкладка останавливают сцену.
- Окружение по локации и времени суток; шаги по пройденному расстоянию и поверхности, позиционные бытовые звуки, вода, готовка, еда, клавиатура, бумага, игрушки, когтеточка, кормушка, купание, костёр, удары спортивных игр, интерфейс и доставка. Звуки спорта в v1 приблизительные, не покадровые.
- CC0 записи короткого лая и мяуканья: public/audio/SOURCES.md. Остальное — оригинальные процедурные звуки, художественную слышимую оценку ещё не делали.
- Команда «Голос» играет только при успешной анимации после подхода. Меню Телефон → Звук: шесть независимых регуляторов, кнопка проверки.
- TypeScript, build, профильные 4/4 теста. Реальный звук Safari/Android требует прослушивания, полный релиз не утверждён.
- Изоляция: ветка feat/living-sound-036, worktree D:\Sim-Life-036-Audio, данные D:\Sim-Life-036-AudioData, порт 3168, тестовый вход без кодов. Main не трогать.

## v2
- По решению владельца звуки машины не добавлять: поездка пока телепортация без видимого движения.
- Настоящие CC0 записи маленькой собаки и кота с более высоким тембром и вариацией скорости; мяуканье особенно писклявое. Это не личные записи владельца; акустическое сходство ещё надо оценить на слух.
- Телевизор звучит по текущей активной программе; один источник на два зрителя. ПК и ноутбук воспроизводят оригинальные синтезированные дорожки по жанру игры/видео после подхода, не при одном открытии меню. Отдельная громкость по типу устройства, источник в фактической позиции экрана, прекращение при отмене, выходе из локации и паузе. Передачи используют стилизованный фон, без настоящей речи.
- Общий media API предусматривает smartSpeaker и stereo; моделей, покупки и управления колонками пока нет, это будущий отдельный этап.
- 6/6 профильных тестов, TypeScript и production build прошли; прослушивание на реальном телефоне впереди.

## v3
- Оригинальные синтетические псевдослоги и смех Влада/Алины с разным тембром, очередность речи по фазе парной анимации, звуки контакта при поцелуе, объятии, high-five, музыка танца. Не копируем Simlish; качество звучания ещё не оценено на физическом телефоне.
- Удары бадминтона и настольного тенниса привязаны к расписанию ударов анимации, теннисный отскок — к формуле траектории. Сигналы не повторяются при повторном кадре и не догоняют пропущенные события после длинного скачка. Звуки укуса по циклу еды, смыв, чистка зубов, открытие/закрытие хранения, качели; остановка звука мира при потере WebGL.
- 8/8 профильных тестов, TypeScript и build прошли. Основной сервер не тронут.

## v4 — завершение звукового фундамента
- Четыре оригинальные инструментальные петли: дневной дом, вечерний дом, парк, танец/концерт. Тихий фон выключается во время звучания ТВ/ПК/ноутбука или явного музыкального действия, чтобы не наслаивать музыку. Регулятор музыки допускает 0%; отдельная громкость голосов персонажей, старые настройки мигрируют автоматически.
- Привязанные к действию одноразовые звуки теперь останавливаются при исчезновении ключа действия; прекращение сцены и пауза очищают источники. Реальные записи питомцев обрезаются до короткой длительности и имеют плавные края. Сами тембры и композиции пока процедурные/черновые, заменяемые.
- 10/10 профильных тестов, включая мок Web Audio для двух независимых клиентов: отмена, смена сцены, пауза и выход, TypeScript/build. Реальный звук на iPhone/Android и совместная сетевая игра не проверены.
- Решение владельца 24.11.2026: полноценные главные карьеры Влада (игровая студия) и Алины (реконструкция волос/салон) отложить до предрелизного этапа, без обязательного номера 0.41. Следующий крупный этап — характер и эмоции, затем семейная жизнь, погода и умный дом. Main — только по отдельному утверждению.
