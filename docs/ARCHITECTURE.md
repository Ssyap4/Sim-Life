# Архитектура Sim-Life — черновик

## Цель
Двухпользовательская мобильная браузерная 3D-игра с общим миром и понятными действиями.

## Первый прототип
- `src/game/World.ts`: Three.js сцена, камера и выбор интерактивных объектов.
- `src/game/Actor.ts`: временные 3D-аватары, движение к цели и простая поза.
- `src/core/state.ts`: базовое состояние, проверка загружаемых данных, сохранение.
- `src/main.ts`: UI и вызов игровых действий.
- `src/style.css`: портретный мобильный HUD.

## Будущая серверная архитектура (ещё не реализована)
- Авторитетное серверное состояние, не доверять клиенту деньги/инвентарь.
- Влад и Алина — отдельные идентификаторы управления одним домохозяйством.
- Команды: запрос действия -> проверка условий сервером -> применение изменений -> трансляция событий.
- Денежные переводы, покупки, инвентарь и размещение — атомарные операции.
- Восстановление после отключения, журнал событий, версии схем состояния.
- Colyseus рассматривается для real-time, выбор хранения данных ещё не утверждён.

## Ограничения демо 0.1
- Нет сетевого сервера и синхронизации.
- Нет настоящего pathfinding: перемещение по прямой может пересекать мебель.
- Покупки/доставка/карьерные мини-игры не реализованы.
- Сохранение через localStorage — только одного браузера и только для временного прототипа.
- Телефоны ещё не проверены по FPS и совместимости.
- Процедурные модели — стилистический набросок, не финальные ассеты.

## Безопасность публичного GitHub
- Не коммитить фото, пользовательские папки, токены, ключи, .env, данные пользователей и приватные ассеты.
- Внешние сервисы и платёжные ключи — только через переменные окружения сервера.
