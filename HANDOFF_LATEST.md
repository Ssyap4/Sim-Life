# Sim-Life — актуальная передача разработки

Дата: 2026-11-19

## Текущий статус
- Старт разработки разрешён автором.
- Рабочая директория: `D:\Sim-Life` на подключённом Windows-компьютере `ALINA-PC`.
- Выбран **предварительный** стек: Vite + TypeScript + Three.js.
- Локальный демо-прототип: интерьер, камера, персонажи, взаимодействия, потребности, семейные деньги и сохранения через localStorage.
- **GitHub:** основной публичный репозиторий — `https://github.com/Ssyap4/Sim-Life`; Git на `ALINA-PC` авторизован под `Ssyap4`, локальный `origin` направлен в этот репозиторий. GitHub в ChatGPT также подключён под `Ssyap4` с правами записи. Ветка `main` опубликована, начальные исходники и коммиты проверены в GitHub. Старый `Syapbl4/Sim-Life` больше не используется.
- **Codex:** не запускался; бережём лимиты.
- **Мультиплеер:** ещё не реализован. В этой версии смена активного персонажа — инструмент тестирования, а не два сетевых пользователя.
- Модели, текстуры и материалы пока процедурные временные заглушки.

## Инварианты концепции
- 2 игрока: Влад / Алина. Общие дом, кошелёк, предметы и прогресс.
- Важные решения принимают игроки; самостоятельность персонажей только в критических потребностях.
- Реконструкция волос ≠ обычное парикмахерское дело.
- Главные системы карьер — реконструкция волос и разработка игр/ПО; другие профессии упрощённые.
- Никаких искусственных лимитов на количество одинаковых бытовых предметов.
- Покупаемые предметы функциональны; комбинированные взаимодействия.
- Клиентская часть оптимизируется для мобильных устройств и вертикального режима.
- Отдельные компактные локации, не бесшовный огромный город.
- Не вводить фальшивые данные или иллюзию работающего онлайна.
