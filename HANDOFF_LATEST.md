## 3. Новое в версии 0.2
- Общие схемы типов, действий и протокола в `src/shared/protocol.ts` с состоянием версии 2.
- `server/logic.ts`: авторитетная экономика/потребности/карьерные действия, строгие проверки прав и ресурсов, immutable result.
- `server/server.ts`: Node HTTP + WebSocket `ws`, 2 реальные роли, выдача индивидуальных сессионных данных, присутствие онлайн, общий бюджет, инвентарь, навыки, snapshots, action events, контроль повторных запросов, heartbeat.
- `server/storage.ts`: отдельные случайные коды игроков в `server-data/access.json`, атомарные серверные сохранения `household.json`, резервная копия `household.backup.json`, отказ при повреждении вместо молчаливого сброса.
- `server/index.ts`: запуск сервера, `vite.config.ts`: прокси WebSocket во время разработки.
- `src/core/network.ts`: клиент WebSocket с автоматическим переподключением.
- `src/main.ts`: новый мобильный экран входа, роли, присутствие, контекстные действия через сервер, мини-магазин демо-доставки, полноценная синхронизация денег/еды.
- `src/style.css`: мобильный интерфейс и экран авторизации с адаптивной версткой.
- `START_SIM_LIFE.cmd` запускает сборку и сервер; `SHOW_INVITES.cmd` открывает приватные коды через Notepad.
- `README.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md` обновлены.
- Версия: `0.2.0`. Старая localStorage-модель 0.1 не мигрируется в сервер: новое сохранение v2 начинается независимо.
- Код пока не содержит финальных моделей, полноценной клиники/города/профессий, real-time duration для игровых действий, pathfinding вокруг мебели.

## 5. Запуск и текущие ограничения
- На ПК: `D:\Sim-Life\START_SIM_LIFE.cmd` либо `npm run build` и `npm run start`. Локально `http://127.0.0.1:3101/`.
- В локальном доверенном Wi-Fi: `http://IP-КОМПЬЮТЕРА:3101/`; у каждого игрока отдельная роль и код.
- Чтобы посмотреть коды, открыть `D:\Sim-Life\SHOW_INVITES.cmd`; коды НЕ отправлять в чат и не публиковать.
- `server-data/`, `.ui-test/`, `node_modules/`, `dist/`, `.npm-cache/` исключены из Git.
- Прототип использует HTTP/WS БЕЗ HTTPS; нельзя открывать в интернете через проброс порта. Для удалённого доступа — отдельное защищённое развёртывание.
- Server-side action applies immediately; ходьба — визуальная анимация на клиентах. Нужны серверные длительности/навигация и аккуратное прерывание для 0.3.
- Проверить доступ по домашней сети после выбора её профиля Private (только если это доверенная сеть), а при необходимости разрешить Node.js в Firewall только для частных сетей.

## 6. Концепция (сохранить)
- Влад и Алина — главные персонажи, Верделл (чёрный пушистый шпиц), Симба (рыжий полосатый кот).
- Только две **глубокие** карьерные ветки: Алина — именно **реконструкция и восстановление волос**, от обучения до собственной физически расширяемой студии с сотрудниками; Влад — **вайбкодинг/фриланс/разработка ПО и игр**, от первых заказов до игровой студии и mini-Tycoon.
- Остальные профессии гораздо проще, как дополнительные способы дохода.
- Общий дом, бюджет, продукты, прогресс. Раздельные камеры и собственное управление, 2 телефона одновременно; второй может быть офлайн без самостоятельных трат.
- Портретная браузерная 3D-игра; мягкий уютный стилизованный облик, не фотореализм; легкие GLB, переиспользование моделей и анимаций, карточки огромных каталогов без загрузки всех 3D-моделей в сцену.
- Управление — тап по объекту, контекстное меню, автоматический подход. Ни джойстика, ни ручного ведения персонажа.
- Камерные отдельные городские локации вместо бесшовного открытого мира.
- Ингредиенты реально покупаются и тратятся; предметы функциональные, могут участвовать в комбинированных действиях.
- Никаких жёстких лимитов «не более одного холодильника/телевизора/ПК»; ограничение — пространство и производительность.
- Отсутствует полная автономная жизнь персонажей: самодеятельность только для красных критических потребностей и без трат/важных решений.
- Плавное развитие семьи, ограниченные редкие поломки, здоровье, кухня, доставки, отношения, клиенты, навыки, бизнесы.
